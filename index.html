🌐 Internet vs. Web: ¿son lo mismo?

No. Son conceptos relacionados pero distintos. Internet es la red física global que conecta dispositivos y redes mediante cables, fibra óptica y señales inalámbricas. La Web (World Wide Web) es solo uno de los servicios que funciona sobre Internet, permitiendo consultar páginas y aplicaciones a través de navegadores.

🌍 Internet
La infraestructura: cables, routers, servidores y protocolos que conectan el mundo. Sin Internet, no hay Web.
🕸️ Web
El sistema de información: páginas, aplicaciones, enlaces y recursos digitales que viajan por Internet.
🔗 Conexión: Así como el correo electrónico o el streaming de video, la Web es un servicio más de Internet, no toda la red.

📄 Página web vs. Aplicativo web

Ambos se abren en un navegador, pero tienen propósitos distintos:

📄 Página Web
Presenta información estática o con pocos cambios. Ej.: página institucional del CASD, artículo de Wikipedia, portafolio personal.
⚙️ Aplicativo Web
Permite interacción y procesos: iniciar sesión, registrar datos, consultar notas, gestionar tareas. Ej.: Google Classroom, correo Gmail.
🔗 Conexión con protocolos: Tanto páginas como aplicativos usan HTTP/HTTPS para comunicarse con el servidor, tema de la siguiente sección.

🖥️ El Navegador Web

Es el programa que interpreta y muestra los recursos de la Web (HTML, CSS, JavaScript). Sin él no podríamos ver páginas ni usar aplicativos.

🔧 Funciones principales
  • Abrir URLs y solicitar recursos
  • Interpretar HTML, CSS y JavaScript
  • Gestionar pestañas, favoritos y descargas
  • Proteger la navegación (modo incógnito, HTTPS)
🌐 Navegadores populares
  • Google Chrome
  • Mozilla Firefox
  • Microsoft Edge
  • Safari · Opera

🔌 ¿Qué son los protocolos?

Los protocolos son conjuntos de reglas que permiten que dispositivos se comuniquen entre sí, sin importar su fabricante o sistema operativo. Sin protocolos, los datos no podrían viajar de forma ordenada por la red.

🔓
HTTP
Transferencia de recursos web sin cifrado
🔒
HTTPS
HTTP con cifrado y autenticación segura
📦
TCP
Entrega confiable y ordenada de datos
📍
IP
Identifica y dirige los paquetes en la red
🗂️
FTP/SFTP
Transferencia de archivos (seguro con SFTP)
🔗 Conexión con DNS: El protocolo DNS traduce nombres de dominio (casd.edu.co) a direcciones IP numéricas. Es el "directorio telefónico" de Internet.

🔒 HTTP vs. HTTPS: diferencia clave

🔓 HTTP
Transfiere datos sin cifrar. Cualquier intermediario podría leerlos. Solo para sitios informativos sin datos sensibles.
🔒 HTTPS
Añade cifrado TLS/SSL: los datos viajan encriptados. Obligatorio para formularios, contraseñas y pagos. El candado verde en el navegador indica HTTPS.
🔗 Conexión con criptografía: El cifrado en HTTPS usa técnicas criptográficas similares a las que estudiaremos en la sección de Enigma/Turing.

📶 Cómo viajan los datos: TCP/IP

1
El navegador envía una solicitud
Escribe una URL → el navegador genera una petición HTTP/HTTPS.
2
DNS resuelve el dominio
Traduce "casd.edu.co" a una dirección IP numérica.
3
TCP divide los datos en paquetes
Garantiza que lleguen todos y en orden correcto.
4
IP dirige cada paquete
Cada paquete puede seguir rutas distintas por la red.
5
El servidor responde
Envía los archivos (HTML, CSS, JS) de vuelta al navegador.

🏗️ Infraestructura de Internet

Para que una página o aplicativo esté disponible en Internet, se necesitan tres componentes esenciales que trabajan juntos:

☁️ Hosting
Servicio que almacena los archivos (HTML, imágenes, bases de datos) y los mantiene disponibles las 24 horas. Ej.: GitHub Pages, Hostinger, AWS.
🌐 Dominio
Nombre fácil de recordar que apunta a una dirección IP. Ej.: casd.edu.co. El DNS traduce el dominio a IP para localizar el servidor.
🖥️ Servidor
Computador potente que responde solicitudes de los usuarios y entrega los recursos (HTML, CSS, JS, imágenes) que piden los navegadores.
🔍 DNS
"Directorio telefónico" de Internet: traduce nombres de dominio a direcciones IP numéricas para que los paquetes lleguen al servidor correcto.

🔄 ¿Qué pasa cuando escribes una URL?

1
Escribes la URL en el navegador
Ej.: https://casd.edu.co
2
El navegador consulta el DNS
DNS convierte "casd.edu.co" → dirección IP del servidor.
3
Se establece conexión con el servidor
TCP/IP garantiza la comunicación segura y ordenada.
4
El servidor envía los archivos
HTML, CSS, JS e imágenes llegan al navegador.
5
El navegador renderiza la página
Interpreta el código y muestra la página visualmente.

🧑‍💻 Alan Turing (1912–1954)

Alan Turing fue un matemático y pionero de la informática cuyas ideas siguen siendo fundamentales hoy. Su trabajo abarca computación teórica, criptografía e inteligencia artificial.

⚙️ Máquina de Turing
Modelo teórico que describe cómo una máquina puede ejecutar cualquier algoritmo. Base matemática de todos los computadores modernos.
🔐 Criptoanálisis en WWII
Contribuyó a descifrar los mensajes de la máquina Enigma nazi, ayudando a acortar la Segunda Guerra Mundial.
🤖 Test de Turing
Propuso un criterio para evaluar si una máquina puede exhibir comportamiento inteligente indistinguible del humano.
🏆 Legado
El Premio Turing (equivalente al Nobel en informática) lleva su nombre. Sus ideas son base de la computación, la IA y la criptografía actual.
🔗 Conexión con Enigma: El trabajo de Turing en criptoanálisis está directamente ligado a la máquina Enigma, tema de la sección de Criptografía.

🐙 Git, GitHub y GitHub Pages

🌿 Git
Sistema de control de versiones: registra cada cambio en tu proyecto. Permite volver a versiones anteriores y trabajar en equipo sin conflictos.
🐙 GitHub
Plataforma en la nube para alojar repositorios Git, colaborar con otros, revisar código y gestionar proyectos.
📡 GitHub Pages
Publica sitios web estáticos gratis desde un repositorio. URL automática: usuario.github.io/repositorio

🛠️ Flujo de trabajo básico

Crear repositorio en GitHub

2
Crear y editar el archivo HTML

3
git add + git commit
Registrar los cambios con un mensaje descriptivo.
4
git push
Subir los cambios al repositorio en GitHub.
5
Activar GitHub Pages
Settings → Pages → seleccionar rama → ¡sitio publicado!
🔗 Conexión con infraestructura: GitHub Pages actúa como hosting + servidor: almacena tus archivos y los sirve con HTTPS automático.

🔐 Criptografía: el arte de ocultar información

La criptografía es la ciencia de transformar información legible en un formato ilegible para quienes no tienen la clave. Ha existido desde la antigüedad y hoy protege cada dato que enviamos por Internet (HTTPS, WhatsApp, bancos).

🔡 Cifrado / Encriptación
Proceso de convertir texto claro en texto cifrado usando un algoritmo y una clave. Solo quien tiene la clave puede descifrar.
🔓 Descifrado / Desencriptación
Proceso inverso: convertir el texto cifrado de vuelta al original usando la clave correcta.

⚙️ La Máquina Enigma

Enigma fue una máquina electromecánica de cifrado usada por Alemania durante la Segunda Guerra Mundial (1939–1945) para enviar mensajes militares secretos.

🔩 ¿Cómo funcionaba?
Tenía rotores, conexiones y configuraciones que cambiaban la sustitución de cada letra. Al presionar una tecla, el mensaje cifrado era distinto cada vez según la posición de los rotores.
🔢 ¿Por qué era difícil de descifrar?
Generaba millones de combinaciones posibles de configuración. Sin conocer la configuración diaria exacta, descifrar era prácticamente imposible de forma manual.
🧮 ¿Cómo la descifraron?
Requirió conocimiento matemático (Turing), análisis de patrones, trabajo en equipo y máquinas especializadas (la Bombe). Fue un esfuerzo colectivo en Bletchley Park.
🌍 Impacto histórico
Descifrar Enigma ayudó a los Aliados a anticipar movimientos enemigos y se estima que acortó la guerra varios años, salvando millones de vidas.
🔗 Conexión con HTTPS: Los principios matemáticos que usó Turing para descifrar Enigma son antecesores de los algoritmos de cifrado modernos que protegen HTTPS hoy.

🔗 Criptografía hoy: de Enigma a HTTPS

🔐
WhatsApp y mensajería
Usa cifrado de extremo a extremo: solo emisor y receptor pueden leer los mensajes.
🏦
Banca en línea
HTTPS con TLS protege transacciones financieras con cifrado de clave pública/privada.
🔑
Contraseñas
Se almacenan como "hashes" (no texto plano): si la base de datos es robada, las contraseñas no quedan expuestas directamente.
